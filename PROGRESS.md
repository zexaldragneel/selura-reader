It reuses exact matching target favorites, including those made by the Copy APK, and otherwise performs exact numeric gallery lookup. It performs a strict metadata transfer with `replace=false`, verifies target identity, favorited state, categories, notes and one-to-one chapter read/bookmark/page progress, **then unfavorites only the original Library entry**. The original manga database row and old-source downloaded files are never deleted. Separate Move cursor keys prevent the prior Copy checkpoint from skipping already duplicated favorites.
