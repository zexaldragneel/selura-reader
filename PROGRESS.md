## Reader Performance 2.0 Phase 2 — early webtoon decode memory budget (2026-10-24)

The existing 128 MiB strip budget, 4 MiB strips, one-decode semaphore, disposal behavior, Webtoon/Pager controls, Phase 1 read-ahead, source limits, HTTP retry and cache format are unchanged.
