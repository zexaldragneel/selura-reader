# Smart collections and Read Next

Open Home  Collections & Read Next (Obsidian), or More  Collections & Read Next in any theme.

Collections apply all selected rules: has unread chapters, has downloaded chapters, completed source status. The downloaded rule is series-level: it does not promise that the unread chapters themselves are downloaded. Create named combinations; delete a rule without deleting its manga. Search matches within the selected collection.

Read Next adds each manga ID only once. Move up/down persists order; remove affects only this queue. Tap the title for native details/reading. Missing library entries remain visible and removable, never silently reassigned to a different source.

Organizer preferences are local app data and survive ordinary in-place APK updates. They are not yet included in Mihon .tachibk export/restore; categories, reading history and existing backups are untouched. No network fetch or recurring storage scan is introduced.

Device acceptance: create a combined rule, read/download a chapter and check refreshed membership, queue three titles, reorder, reopen the app and confirm order, remove one and verify categories/history remain. Test empty/search states, large text and both Obsidian and another theme.
